# Legacy Vite Prototype

This is the original hand-built Vite + vanilla TypeScript implementation of
the VELLMONT site (canvas-based scroll animations with GSAP + Lenis),
preserved for reference after the project moved to Next.js.

It is not part of the active build — see the root README for the current
Next.js app.

To run it standalone:

```sh
cd legacy-vite
npm install
npm run dev
```
